# 0.1.0 验证范围

验证环境：macOS arm64、官方 DeepSeek Harness **0.2.1-rc.3** 内置 CLI 与独立 Web Host，独立资料目录，不含用户账号或 API Key。

## 已验证

- 18 项自动化测试通过：动画阶段与跳过、减少动态效果、超时兜底、重复启用、观察器释放、原生节点保留、配色覆盖层释放，以及本地图片读取边界。
- 实际 `.tgz` 安装成功；配置展开后出现主题插件。
- 通过原厂 PluginManager 停用、启用，再通过 CLI 卸载：插件项和依赖按预期移除；内置外观偏好文件的 SHA-256 保持一致。
- 不兼容版本测试包被宿主拒绝，依赖声明与锁文件恢复。
- 正式索引注入、模块图与客户端脚本返回正常，页面实际显示主题。
- 在原生插件管理页关闭主题后重启 Host，页面恢复原生外观，模块图和索引不含主题。重新启用后主题恢复。
- 输入区可输入、清空中英文和代码草稿；草稿未发送。原生栏宽拖动可用。
- 在 1200×640、1200×800、720×640 视口检查布局。短窗口隐藏档案插页；窄窗口沿用原生工具栏全屏行为，关闭工具栏后输入区位于视口内。
- 发布前扫描通过：未发现个人绝对路径、凭据特征、系统衍生字体、原作图像或应用归档文件；无安装生命周期脚本。

## 限制

- 未验证 Windows、Linux 及其他 Harness 版本；当前只声明精确版本兼容。
- 此次真实界面验证使用 Web Host；没有替换用户当前桌面应用或迁移其账号资料。
- 未调用在线模型，未验证模型供应商、计费或网络服务。
- 内置 schema 检查存在与未装主题的原版基线相同的四条 preset carrier 诊断；主题自身 Config 可识别，没有新增诊断。
- 未启用 HMR 的 Host 开关需要重启生效。刷新网页不等于重启 Host。
- 默认公开图形是原创程序绘制。用户自备原作素材的显示与其文件有关，默认预览不展示随包未包含的图片。
